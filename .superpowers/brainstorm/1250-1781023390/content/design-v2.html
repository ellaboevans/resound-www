Animation Spec

Expand (pill → card)

  • Spring: duration: 0.4, bounce: 0.08
  • Pill scales from origin at top-center of screen
  • Content staggers in at 30ms intervals with translateY(6px)
  • Backdrop blur ramps 24px → 40px
  • Border highlight fades in

Collapse (card → pill)

  • Fast: 200ms ease-out (asymmetric timing)
  • Content fades out first (100ms)
  • Then card shrinks to pill
  • Blur drops 40px → 24px
Easing: cubic-bezier(0.23, 1, 0.32, 1) — strong ease-out for all transitions.
clip-path trick: Expand uses clip-path: inset(0 50% 0 50%) → inset(0 0 0 0) for the pill-to-card morph.
Never scale(0): Everything starts from scale(0.95) + opacity(0).
